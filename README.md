
# Taller III - Bases de Datos I

## Sistema de Gestion de Reservas para un Hotel

Universidad de Manizales

Asignatura: Bases de Datos I

## Objetivo

Implementar una base de datos relacional en PostgreSQL 18
para gestionar clientes, habitaciones, reservas y pagos
de un hotel.

## Herramientas

- PostgreSQL 18
- pgAdmin 4
- Visual Studio Code
- Git y GitHub

## Desarrollo

El proyecto se desarrollara mediante scripts SQL
versionados con Git, incluyendo:

1. Diseno fisico y DDL.
2. Restricciones de integridad.
3. Datos sinteticos.
4. Manipulacion de datos y consultas SQL.
5. Vistas y transacciones.
6. Validacion NL2SQL.
